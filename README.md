# Python Vibe Coding Lab1

## 一、实验简介

本项目是 Python Vibe Coding 实操实验，使用 Python 和 AI 辅助编程工具完成 Excel 销售数据的清洗、统计与报表生成。

实验采用分步骤开发的方法，先分析需求，再利用 AI 辅助生成代码，并通过实际运行和人工核对检查结果，同时使用 GitHub 保存代码修改记录。

## 二、开发环境

- 操作系统：Windows
- 开发工具：Visual Studio Code
- Python 版本：3.14.2
- 主要依赖库：pandas、openpyxl
- 版本管理工具：Git、GitHub

安装依赖：

```bash
python -m pip install pandas openpyxl
```

## 三、项目文件说明

- `main.py`：读取 Excel、清洗数据、统计销售额并生成报表
- `create_sample.py`：生成包含正常数据和异常数据的测试文件
- `sales_raw.xlsx`：原始销售测试数据
- `report.xlsx`：程序生成的销售统计报表
- `docs/requirements.md`：实验需求澄清清单
- `README.md`：项目说明文档

## 四、程序运行方法

1. 安装 Python 3.10 或以上版本。
2. 安装 pandas 和 openpyxl。
3. 在项目目录中打开终端。
4. 执行以下命令生成测试数据：

```bash
python create_sample.py
```

5. 执行以下命令生成销售报表：

```bash
python main.py
```

运行成功后，项目目录中会生成 `report.xlsx`。

注意：重新运行 `create_sample.py` 会覆盖同名的 `sales_raw.xlsx`，运行前应确认原始文件是否需要保留。

## 五、主要功能

### 1. 数据清洗

程序读取原始 Excel 文件后，完成以下操作：

- 删除关键字段存在空值的数据
- 删除数量小于或等于 0 的记录
- 根据全部字段删除重复记录
- 计算每条有效记录的销售额

销售额计算公式：

销售额 = 数量 × 单价

### 2. 销售统计

程序支持以下统计功能：

- 按销售员统计销售额
- 按地区统计销售额
- 按月份统计销售额

### 3. 生成 Excel 报表

输出文件为 `report.xlsx`，包含四个工作表：

- 明细清洗后
- 按销售员
- 按地区
- 总览

## 七、异常测试结果

| 测试项目 | 预期结果 | 实际结果 |
|---|---|---|
| 输入文件不存在 | 提示找不到文件 | 通过 |
| 缺少必要字段 | 指出缺少的字段 | 通过 |
| Excel 只有表头、没有数据 | 提示没有销售数据 | 通过 |
| 清洗后没有有效记录 | 提示无有效销售记录 | 通过 |

测试过程中对原始数据进行备份，完成测试后恢复正常文件，避免影响后续实验。

## 八、AI 协作与 GitHub 版本管理

本实验通过 AI 辅助完成需求分析、代码编写、错误处理和测试方案设计。

开发过程中将任务分为多个阶段：

1. 明确需求并编写需求清单
2. 创建 Python 项目与测试数据
3. 编写数据清洗功能
4. 实现销售额分类统计
5. 生成 Excel 报表
6. 添加异常处理
7. 进行正常测试和异常测试

每个主要开发阶段通过 Git 提交代码，利用 GitHub 的提交历史与 diff 记录程序的修改过程。
