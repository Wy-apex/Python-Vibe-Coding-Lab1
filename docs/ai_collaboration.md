# Python Vibe Coding 实验一：AI 协作过程记录

## 一、实验任务与协作方式

本次实验使用 Python 完成 Excel 销售数据清洗与报表生成，并使用 ChatGPT 辅助分析需求、编写代码和设计测试用例。

开发过程中，我没有一次性让 AI 生成完整项目，而是先明确实验需求，再将任务拆分为多个小步骤，每完成一个功能就运行测试，并通过 GitHub 提交代码。

## 二、需求分析与任务拆分

在开始编写代码之前，我与 AI 明确了以下要求：

1. 输入文件为 `sales_raw.xlsx`，包含日期、销售员、产品、数量、单价和地区六个字段。
2. 删除关键字段缺失、数量小于或等于零以及重复的数据。
3. 根据销售员、地区、月份统计销售额。
4. 生成包含四个工作表的 `report.xlsx`。
5. 对文件不存在、字段缺失、空文件和无有效数据等情况进行异常处理。
6. 不修改原始销售数据，并保留测试及版本管理记录。

需求清单保存在 `docs/requirements.md`。

## 三、AI 辅助开发过程

### 阶段一：开发环境准备

**向 AI 提出的需求：** 指导配置 Python 开发环境，并将本地 VS Code 项目连接到 GitHub。

**AI 提供的帮助：** 说明了 Python、pip、pandas、openpyxl 和 Git 的使用方法，并指导完成仓库克隆及代码推送。

**人工操作与验证：** 我检查了 Python 3.14.2 和 pip 的版本，安装所需库，运行了第一个 Python 测试程序，并解决了 GitHub 网络连接问题。

### 阶段二：创建测试数据

**向 AI 提出的需求：** 生成包含正常销售记录、重复行、空值和异常数量的 Excel 测试数据。

**AI 提供的帮助：** 提供了 `create_sample.py` 代码，使用 pandas 生成 `sales_raw.xlsx`。

**人工操作与验证：** 我运行程序，确认原始 Excel 包含 8 条记录，并将测试数据上传到 GitHub。

### 阶段三：实现数据清洗

**向 AI 提出的需求：** 使用 Python 读取 Excel，并删除空值、数量异常和重复记录。

**AI 提供的帮助：** 提供了 pandas 数据清洗代码，包括 `dropna()`、条件筛选、`drop_duplicates()` 等操作。

**人工操作与验证：** 我运行程序，确认原始 8 条数据清洗后保留 3 条有效记录，销售总额为 1200 元。

### 阶段四：销售统计与报表生成

**向 AI 提出的需求：** 根据销售员、地区及月份统计销售额，并输出四个工作表。

**AI 提供的帮助：** 提供了 `groupby()` 分组统计和 `ExcelWriter()` 报表输出代码。

**人工操作与验证：** 我核对了销售员和地区的销售额，在 WPS 中打开生成的 `report.xlsx`，确认四个工作表存在且统计结果正确。

### 阶段五：异常处理与测试

**向 AI 提出的需求：** 让程序在出现异常输入时显示容易理解的错误提示，而不是直接报错退出。

**AI 提供的帮助：** 指导添加文件存在性、必要字段、空文件及清洗后无有效记录等检查。

**人工操作与验证：** 我分别修改测试输入并运行程序，确认以下四项异常能够得到正确提示：

- 输入文件不存在
- Excel 缺少「销售员」字段
- Excel 只有表头，没有数据
- 数据数量全部小于或等于零，清洗后没有有效记录

每次测试完成后，我都会恢复原始数据，再运行程序确认正常功能没有受到影响。

## 四、人工代码审查与风险检查

本次实验重点检查了以下问题。

**1. 数据正确性**

对销售额计算公式进行了人工核对：

- 张三：2 × 50 = 100 元
- 李四：3 × 100 = 300 元
- 王五：1 × 800 = 800 元

总销售额为 1200 元，与程序结果一致。

**2. 原始数据保护**

程序读取 `sales_raw.xlsx`，将统计结果输出到独立的 `report.xlsx`，避免直接覆盖原始数据。异常测试时先备份，再修改测试文件，测试后恢复。

**3. 异常处理**

检查程序在文件缺失、字段缺失、空文件以及没有有效数据时，能否输出明确提示。

**4. 仍需注意的风险**

当前程序使用基本的数据检查方法，对于复杂的输入类型、日期格式错误、损坏的 Excel 文件以及部分不合理金额，还需要进一步完善验证。现有测试不能代表已经覆盖所有异常情况。

## 七、实验复盘

通过这次 Vibe Coding 实验，我认识到，使用 AI 编程并不是简单地复制代码，而是需要自己明确需求、理解程序实现的功能，并通过测试判断结果是否正确。

本次实验中，AI 主要帮助我编写代码、解释错误和设计测试步骤；而环境配置、程序运行、Excel 结果核对、异常测试以及 GitHub 提交等操作由我实际完成。

在实验过程中，我遇到了 GitHub 连接失败、终端命令引号处理异常等问题。通过逐步检查网络代理、查看错误信息和调整操作方法，最终解决了这些问题。

这次实验让我进一步熟悉了 Python 数据处理、Excel 报表生成和 GitHub 版本管理，也让我认识到，在 AI 辅助编程过程中，人工验证和过程记录同样重要。
