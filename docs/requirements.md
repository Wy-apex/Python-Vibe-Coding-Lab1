实验一：Excel 销售报表生成——需求澄清清单

1. 实验目标
使用 Python 编写一个 Excel 报表生成脚本，读取原始销售数据，完成数据清洗、销售额统计，并生成新的 Excel 报表。

2. 输入要求
- 输入文件：sales_raw.xlsx
- 文件格式：Excel（.xlsx）
- 必须包含六个字段：日期、销售员、产品、数量、单价、地区
- 原始数据可能存在空值、重复行、数量为负数或零等情况

3. 数据清洗要求
1. 删除关键字段存在空值的记录。
2. 删除数量小于或等于 0 的异常记录。
3. 根据全部字段删除重复记录。
4. 清洗时不得修改原始 Excel 文件。

4. 数据统计要求
1. 销售额 = 数量 × 单价。
2. 按销售员分别统计销售总额。
3. 按地区分别统计销售总额。
4. 计算月度销售总额。

5. 输出要求
生成 report.xlsx 文件，包含四个工作表：
- 明细清洗后
- 按销售员
- 按地区
- 总览

6. 异常情况处理
1. 输入文件不存在时，显示明确的错误提示。
2. 缺少必要字段时，指出缺失的字段。
3. Excel 文件为空时，显示提示信息。
4. 数据清洗后没有有效记录时，显示提示信息。
5. 程序遇到异常输入时，应尽可能给出容易理解的错误提示。

7. 验收标准
1. 程序能够正常运行并生成 report.xlsx。
2. 清洗后的数据满足实验要求。
3. 销售员、地区及月度销售额统计正确。
4. 至少完成一个正常测试和两个边界或异常测试。
5. 保留测试结果截图和 AI 协作过程记录。

8. AI 协作计划
本实验使用 AI 辅助完成 Python 程序设计。
计划将任务拆分为需求分析、数据准备、数据清洗、销售统计、报表输出、异常处理和测试验证。
每完成一个步骤，人工检查代码与运行结果，并通过 GitHub 保存代码修改记录。
对于数据清洗规则、金额统计结果、异常处理和原始数据保护等关键内容，进行人工核对。
